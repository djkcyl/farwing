# Farwing Client 使用说明（Windows）

Farwing Client 是 Farwing 的 Windows 客户端，可作为主控（观看、控制其他设备）和被控（被其他设备连接）。所有账号、设备与会话协调都通过你自建的 Farwing Server 完成，客户端不连接任何第三方服务。

## 1. 准备

- Windows 10/11 x64。
- 一台可访问的 Farwing Server（部署见 [server/README.md](../server/README.md)），以及管理员在网页端为你创建的账号（或邀请码注册）。
- 服务器使用自签名证书时，向管理员索取证书 SHA-256 指纹（服务器启动日志会打印）。

## 2. 首次登录（图形界面）

登录分两步：先选服务器，再登录账号。两步都不是必须的。

1. 运行 `Farwing.exe`。第一步“连接服务器”：填写服务器地址，例如 `farwing.example.com`（服务器不用 443 端口时带上端口，如 `farwing.example.com:8443`），点“检查证书”。
   - 证书受系统信任或与填写的指纹一致时，直接进入下一步。
   - 不受信任时会显示服务器证书的 SHA-256 指纹，与管理员提供的核对无误后，点“信任此证书并继续”（也可以事先在“证书指纹”栏粘贴）。
   - 不使用服务器时，点“不使用服务器 · 局域网直连”。
2. 第二步“登录账号”：显示所选的服务器（点“更换”回到第一步），填写用户名与密码后点“登录”。这一步也可以选“无需登录”：“让别人连接本机”或“连接其他设备”。
3. 登录成功后进入设备中心。同账号下的电脑出现在“设备 → 我的设备”中。

不登录也可以进入设备中心，能用的功能取决于有没有设置服务器（`docs/access-model.md` §2.5）：

| 功能 | 不使用服务器 | 有服务器、未登录 | 已登录 |
| --- | --- | --- | --- |
| 设备 · 附近、最近（地址或局域网直连） | ✓ | ✓ | ✓ |
| 设备 · 用设备 ID 或短号经服务器连接 | — | ✓（对方信任本机或用访问码） | ✓ |
| 设备 · 我的设备、好友共享、收藏 | — | — | ✓ |
| 本机 · 访问码、受信任设备、正在连接 | ✓（只能直连） | ✓（也可经服务器） | ✓ |
| 好友 | — | — | ✓ |
| 设置 · 被控设置 | ✓（关机重启、局域网唤醒协助除外） | ✓（同左） | ✓ |
| 后台服务 | ✓ | ✓ | ✓ |
| 其他设置 | ✓ | ✓ | ✓ |

不能用的入口带锁标，点开会说明原因，并提供“登录”（或“设置服务器并登录”）按钮；左下角显示“未登录”和“登录”。选过“不使用服务器 · 局域网直连”或“无需登录”后，下次打开直接进入设备中心。

已经保存过服务器时，启动后直接从第二步开始。登录后要换服务器，在“设置 → 账号与服务器”中点“更换服务器…”：确认后退出当前账号，回到第一步填写新的地址。

服务器地址与证书指纹按 profile 保存在 `%LOCALAPPDATA%\Farwing\server.json`；账号与设备凭据只保存在 Windows 凭据管理器中（安装后台服务后为 DPAPI 保护的服务保险库）。

## 3. 设备身份、访问与连接方式

完整的设计见 [access-model.md](access-model.md)。三个概念：

- **设备 ID**：由本机设备密钥推导的 16 位 ID（显示为 `abcd efgh ijkl mnop`）。同一台设备在任何服务器、局域网、直连中都是同一个 ID，它本身就是设备指纹：对方出示的密钥与 ID 不符时连接会被拒绝。`Farwing id` 显示本机的设备 ID 与公钥。
- **短号**：服务器分配的 9 位号码，只是方便口头告诉别人的“拨号别名”，需要服务器。
- **谁可以连接本机**（本机判定，所有权限再与本机上限取交集）：

| 谁 | 怎样证明 | 权限 | 经服务器 | 直连 |
| --- | --- | --- | --- | --- |
| 本账号的其他设备 | 账号 | 全部 | ✓ | ✓ |
| 好友 | 账号与你给的授权 | 你在“好友”页给的权限 | ✓ | ✓ |
| 受信任设备 | 设备密钥 | 信任时选定，可修改 | ✓ | ✓ |
| 访客 | 访问码，或你在本机确认 | 访客权限 | ✓ | ✓ |

连接时只需要告诉 Farwing 连谁（设备 ID、短号或地址），怎么连（局域网直连、经服务器 P2P、TURN 中转）自动选择。

## 4. 命令行

```powershell
Farwing.exe server probe farwing.example.com:8443     # 查看证书指纹与服务器信息（不保存）
Farwing.exe server set farwing.example.com:8443 --pin <SHA-256 指纹>
Farwing.exe server show
Farwing.exe login --username alice                       # 交互输入密码（不回显）
Get-Content pw.txt | Farwing.exe login --username alice --password-stdin
Farwing.exe id                                           # 本机的设备 ID 与公钥
Farwing.exe devices                                      # 列出账号设备与好友共享的设备
Farwing.exe connect --device-id <设备ID>                 # 打开观看窗口
Farwing.exe connect --device-id <设备ID> --transport relay   # 强制经 TURN 中继
Farwing.exe connect --device-id <设备ID> --audio-only        # 仅接收声音
Farwing.exe host --allow                                 # 无窗口被控：开启“允许连接本机”并保持在线，Ctrl+C 退出
Farwing.exe host --allow --allow-ports                   # 同时允许端口转发
Farwing.exe host --allow --access-code <访问码>          # 同时开启访问码，输出短号
Farwing.exe assist <短号或设备ID> [--code <访问码>]      # 经服务器连接（无需登录；对方信任本机时不用访问码）
Farwing.exe friend list                                  # 好友与待处理申请
Farwing.exe friend add <用户名>                          # 发送好友申请；accept/reject/cancel <申请ID>，remove <用户ID>
Farwing.exe grant show <好友用户ID>                      # 给某位好友的权限
Farwing.exe grant set <好友用户ID> --default view,annotation --device <设备ID>=view,control,clipboard
Farwing.exe sessions [--revoke <设备ID>]                 # 本账号的登录设备，可注销
Farwing.exe logout

# 受信任设备
Farwing.exe trusted list                                 # 本机信任的设备，以及信任本机的设备
Farwing.exe trusted add <设备ID> --key <公钥> [--name 名称] [--grants view,control]
Farwing.exe trusted grant <设备ID> view,control,files    # 修改它能做什么
Farwing.exe trusted remove <设备ID>                      # 不再信任（断开它的连接）

# 直连（不经服务器）
Farwing.exe lan                                          # 发现局域网中的设备
Farwing.exe connect --direct 192.168.1.20                # 本账号设备、好友、信任本机的设备（默认端口 28890）
Farwing.exe connect --direct 192.168.1.20 --code <访问码>    # 作为访客（--ask：请对方确认）
Farwing.exe host --serverless --allow [--access-code <访问码>]   # 不登录、不连接服务器，只接受直连
```

`--profile <名称>` 可用于任意命令（见第 7 节）。`host` 启动时会先预检本机采集与编码能力（首次约 10 秒），然后上线，避免第一次连接超时。

观看窗口默认“仅观看”，需要键鼠控制时在窗口菜单中开启。剪贴板（含文件）在控制时默认双向同步；密码管理器等声明“不同步”的剪贴板内容不会被发送。不自动同步时（仅观看、关闭了“剪贴板同步”，或多人会话中没有键鼠控制权），可以用窗口菜单“获取被控剪贴板”把被控端当前的剪贴板复制到本机（需要“剪贴板”权限，内容在粘贴时才传输）。

## 5. 作为被控端（“本机”页）

“本机”页回答一个问题：谁可以连接这台电脑。

- **本机**：设备 ID 与短号（点击复制）、对方可以输入的局域网地址，以及总开关“允许连接本机”。关闭时任何人都连不上本机。
- **访问码**：开启后，对方输入访问码（或经你确认）即可作为访客连接，只对这一次连接有效。
  - 访问码设置（齿轮）：访客怎样连接（访问码 / 访问码 + 本机确认 / 仅本机确认）、访问码类型（临时访问码，可随时换一个 / 固定访问码，长期有效 / 两种都接受）、临时访问码更换（每次连接后、每小时到每周，或从不；默认每天，“每次连接后”在最后一位访客断开后更换；改选后从此刻重新计时），以及“访客可以”。命令行 `host --access-code` 指定的临时访问码不自动更换。
  - “复制邀请”复制设备 ID、短号与访问码，发给对方。设置了服务器（且没有开启“仅直连”）时还附带一个浏览器链接：对方打开后网页端的访客页已填好设备 ID 与访问码（固定访问码不放进链接）。
  - 访问码不离开本机，也不发给服务器：双方用 SPAKE2 核对（经服务器时由服务器转发消息），连续输错 10 次会暂停 5 分钟。
- **受信任设备**：无需访问码和确认即可连接本机，经服务器或直连都可以，按各自的权限（可修改、移除）。信任一台设备的方式：
  - 它作为访客连接时，在“正在连接”中点“信任”；
  - 连接请求（需要本机确认时）中选“允许并信任”；
  - 命令行 `trusted add <设备ID> --key <公钥>`（对方用 `Farwing id` 查看）。
  信任时的权限为当前的访客权限。
- **本账号的设备与好友**：本账号的其他设备可以完全控制本机；好友按你在“好友”页给的权限（新好友默认只有“观看”和“批注”；“默认都不共享”时，没有单独设置的设备对好友完全不可见）。两者在同一局域网时也可以直连本机：本机缓存账号设备与好友授权（好友授权的缓存在服务器可达时随时更新，撤销立即生效）。
- **正在连接**：所有参与者，可以单独断开、“禁止控制”或“信任”（访客）。
- **上限**：文件、剪贴板、端口转发、关机重启（需登录）与同时连接人数对所有人生效，在“设置 → 被控设置”中修改。
- 受信任设备、好友共享的设备、好友权限设置与访问码卡片中，权限以一排图标显示（顺序同权限编辑器），鼠标悬停显示每个图标的含义。
- 所有设备列表（我的设备、好友共享、附近、最近与收藏、受信任设备，以及网页端）都按设备名排序，名称相同时按设备 ID，刷新不会改变顺序；“我的设备”可改为“在线优先”。
- **配对**：在“设备 → 附近”中对一台设备点“配对”，两边各显示同一个 6 位配对码；核对相同后在两台电脑上都点“配对”，两台设备即互相成为受信任设备（完全控制），以后互相连接无需访问码或确认。码不同时请取消。
- 未登录时同样可以开启访问码、信任设备（登录页第二步“让别人连接本机”）；有服务器时对方可以用设备 ID 或短号经服务器连接，没有服务器时只能直连。
- 安装后台服务（侧边栏“安装服务”、“本机”页或“设置 → 被控设置 / 后台服务与驱动”）后，可在锁屏、未登录 Windows 时接入，并开机自动在线。安装需要管理员授权，不需要登录账号：未登录时服务按访问码、受信任设备和直连接受连接（没有服务器或开启“仅直连”时只接受直连），登录后自动改用账号。安装时本机的受信任设备与直连开关交给服务，此后保存在服务里（普通用户无法改写），界面与 `trusted` 命令通过服务读取和修改，移除信任会立即断开该设备的连接；卸载服务时再交还本机。
- 多人同时连接：默认最多 8 位参与者可以同时观看或控制，上限可改为 1–16 人。
  - 键鼠控制权先到先得：同一时刻只有一人能开启键鼠控制；持有者关闭键鼠控制、断开或被收回控制权限后，其他人才能开启。
  - 上次开着键鼠控制的主控重新连接时，只有它独自连接才会自动恢复控制；已有其他人连接时需要手动开启。
  - 没有控制权的参与者统一观看一路 1080p · 60 FPS 的观影模式画面（同一屏幕只编码一次，节省本机的编码与上行带宽），选了“流畅”的观看者看 720p 的一路；持有控制权的人使用自己的画质设置。只听声音（仅音频）的参与者不算观看者：一人看画面、一人只听声音时，看画面的人仍用自己的画质设置。切到仅音频会交还键鼠控制权；切回画面后从切换前的码率继续。
  - 每位参与者的光标带昵称显示在本机屏幕上（不会出现在远程画面里）。
  - 有人修改分辨率、DPI、虚拟屏或超级屏时，其他参与者会看到提示。
  - 多人时剪贴板只与持有控制权的参与者自动同步；其他拥有“剪贴板”权限的参与者可以在窗口菜单中手动“获取被控剪贴板”。多人的麦克风会混音后送入虚拟麦克风。
- 本机即将睡眠 / 休眠、或切换 Windows 用户时，已连接的主控会收到提示并等待本机恢复。远程重启 / 关机前，已连接的主控会收到通知，并在本机重新上线后自动重连。
- 直连：允许连接时，本机在 TCP 28890（被占用时顺延到 28891…）接受直连，并在局域网中广播自己（“设置 → 被控设置 → 直连与局域网”可关闭或改端口）。
  - 服务器不可达时，本机仍接受直连，并在后台继续重连服务器。“仅直连（不连接服务器）”或 `host --serverless` 让被控完全不使用服务器。
  - 从公网直连：在路由器上转发 TCP 28890 与 UDP 28890 到本机（端口按设置；所有直连会话共用这一个 UDP 端口），并在 Windows 防火墙中允许 Farwing。
  - 直连开关（允许直连、端口、局域网发现）与“仅直连”修改后立即生效：被控端按新设置重新连接（安装了后台服务时由服务完成）。

## 6. 作为主控端（“设备”页）

- 页面上方是唯一的连接入口：输入**设备 ID、短号或地址**，点“连接”。
  - 本账号或好友共享的设备 ID：经账号连接；在局域网中的设备：直连；其他设备 ID 与短号：经服务器请求连接；地址（`主机名或 IP[:端口]`，IPv6 写作 `[地址]:端口`）：直连。
  - 对方信任本机、或是本账号与好友的设备时不需要访问码；否则填写“访问码”，或勾选“不用访问码，请对方确认”。经服务器时对方要求访问码会弹出输入框。
  - 输入框下方会提示这次将怎样连接。
- 下面是一份设备列表，按来源分为四个标签：
  - **我的设备**：账号下的电脑（搜索、在线筛选、排序；底部“本机与其他登录设备”可改名或移除）。
  - **好友共享**：好友共享给你的设备，按好友分组，标出可以做什么；在局域网中时标“可直连”。
  - **附近**：同一网络中开启了发现的设备，按设备 ID 认出它是谁：本账号、某某共享、对方信任本机，或需要访问码（“输入访问码”/“请对方确认”）。
  - **最近与收藏**：收藏的短号（可在本机保存访问码），以及连接过的设备（本机记录与账号的经服务器记录合并，同一台设备只出现一次），标出“对方信任本机”。
  - 四个标签用同一种列表：上方左侧搜索，右侧是该标签的筛选、排序或操作；每台设备一行（缩略图、名称与状态标记、一行 ID 与说明，操作在右侧，主要操作在最右）；列表为空时在同一位置说明原因。
- 服务器状态只在窗口底部的状态栏显示：未设置服务器、未登录、正在连接服务器、已连接服务器、无法连接服务器（附下次重连的倒计时与“立即重连”）。
  - 需要服务器的内容无法读取时，在内容的位置显示原因和对应的操作（设置服务器 / 登录 / 立即重连），页面上不再另加提示。
  - 需要服务器的按钮（添加好友、收藏、改名与移除设备、检查更新等）在服务器不可用时变灰，悬停显示原因。
  - 服务器恢复后，失败的读取（好友、收藏、设备详情、更新检查）自动重做。
- 列表、设备详情、观看窗口的“切换设备”菜单与“正在连接”都显示设备 ID；同一台设备在所有地方的 ID 相同。
- 侧边栏“通知”（需登录）：带未读数；新通知按“通知方式”弹出卡片或 Windows 通知；页面下方逐项开关（[notifications.md](notifications.md)）。
- 侧边栏“记录”（需登录）：“连接”列出本账号的设备作为被控或主控的每一次连接（点开看来源、连接方式、画面概况、是否用过键鼠控制、文件传输与端口转发），“账号”列出登录、安全、设备、好友与访问码设置的变化，内容与网页端“记录”相同（[connection-records.md](connection-records.md)）。
- 设置集中在侧边栏的“设置”中：账号与服务器、被控设置、连接其他设备、网络、快捷键、插件、后台服务与驱动、本机诊断、日志、关于。“被控设置”包含别人连接本机时的一切：总开关、后台服务、直连与局域网、权限上限、画面与声音、通知；“网络”只有主控与被控都用的打洞与端口映射。
- 目标已有其他人连接时直接加入，不会顶替对方；工具栏的“参与者”按钮列出所有人和当前持有控制权的人。
  - 多人时开启键鼠控制即获得控制权，关闭即交还；别人持有时键鼠按钮变灰，悬停显示谁在控制。
  - 没有控制权时画面为 60 FPS 观影模式，画质只能选自动、高清（1080p）或流畅（720p）；选“自动”时网速不够会换到流畅，网速恢复后换回。获得控制权后恢复你自己的画质设置（可使用低延迟）。
  - 麦克风不需要开启键鼠控制。
- 多人连接时，其他参与者看到的你的光标颜色可在“设置 → 连接其他设备 → 我的光标颜色”中选择（默认按加入顺序分配），下次连接生效。
- 键盘按物理位置发送（与两端键盘布局无关），由被控端的输入法组字；Caps/Num/Scroll 锁定状态会同步。Ctrl+Alt+Del、锁屏、任务管理器、显示桌面、任务视图在菜单中发送。
- 画质菜单：
  - 画质：自动、原画、超清、高清、流畅（720p · 60 FPS，约 1.5 Mbps）、自定义。手动选的档位频繁卡顿时，画面上方提示可以改为低一档。
  - “网络不佳时”可选“优先降低码率”（默认）或“优先降低帧率”，分辨率不随网络变化。
  - “观影模式”适合看视频：播放更平稳、音画同步，延迟略高。两项都按设备记住。
- 连接中断时会自动恢复：先在会话内重建网络路径；会话丢失后在 5 分钟内自动重连，被控离线时显示“等待设备上线”，上线后立即重连。关闭窗口可随时取消。直连会话断开后同样会自动重新直连（最长 5 分钟）。
- 对方出示的密钥与它的设备 ID 不符时（冒充），连接立即被拒绝。
- 端口转发的目标地址可以是 IP 或主机名（在被控端解析），支持 TCP 与 UDP。

## 7. 同一台电脑运行多个实例（开发/测试）

每个 profile 拥有独立的数据目录、凭据、设备身份与单实例锁：

```powershell
Farwing.exe --profile a gui
Farwing.exe --profile b gui
```

或设置环境变量 `FARWING_PROFILE=b`。默认 profile 为 `default`，数据在 `%LOCALAPPDATA%\Farwing`；其他 profile 的数据在 `%LOCALAPPDATA%\Farwing\profiles\<名称>`。后台服务、驱动等全机组件只属于默认 profile；非默认 profile 以便携模式运行（不使用后台服务提供的锁屏接入、服务端输入注入等能力），也不会显示或执行“安装服务”；从哪个程序文件启动就运行哪个，不转交给已安装的版本。

同一台电脑上一个 profile 作为被控、另一个作为主控时，被控画面就是本机桌面，观看窗口会出现“画中画”；本机声音也会被播放两遍，测试时可加 `--mute`。

## 8. 驱动

虚拟显示、输入和虚拟声卡驱动是可选组件。`assets/drivers/` 附带用项目自签名证书（`CN=Farwing Drivers`）签名的三个驱动包，构建时嵌入客户端。安装驱动时程序请求管理员授权，并把该证书加入本机“受信任的根证书颁发机构”与“受信任的发布者”；内核虚拟声卡还需要测试签名模式。改用你自己的证书时，按 [drivers/README.md](../drivers/README.md) 重新构建签名后替换 `assets/drivers/`。未包含驱动包的构建中，相关安装入口会提示“该构建未包含 Farwing 驱动包”，其余功能不受影响（输入使用系统输入注入）。

## 9. 开发验证命令（隐藏）

用于验收和排查，不打开窗口，直接调用与设备中心相同的功能服务：

```powershell
Farwing.exe dev ports --device-id <ID> --local 127.0.0.1:28090 --remote 127.0.0.1:80 [--udp] [--seconds 30]   # --remote 也可填 主机名:端口，在被控端解析
Farwing.exe dev files --device-id <ID> --list "D:\data" [--download "D:\data\a.bin" --to "C:\tmp"] [--upload "C:\tmp\b.txt" --remote-dir "D:\data"]
Farwing.exe dev diagnostics --device-id <ID> [--cancel-after-ms 800]   # 取消后不应留下 .zip.partial
Farwing.exe dev power --device-id <ID> [--shutdown]       # 真实发送电源请求；被控端开启“远程电源”时会实际执行
```

`dev video` 不开窗口地解码被控主屏，可在主控收包处注入丢包与延迟，结束时输出 JSON：解码帧数、关键帧数、PLI 数、每次丢包后的恢复时长与冻结时长（p50 / p95）、恢复用的帧的大小等，用来量丢包恢复（[rfi-ltr-brief.md](protocol/rfi-ltr-brief.md) §6.10）：

```powershell
Farwing.exe dev video --device-id <ID> [--seconds 60] [--codec h264|h265|av1] [--software] [--no-recovery] [--recovery-late] [--fps 60] [--loss "frame:300,every=120;delay:40"]
```

`--loss` 的规则用分号分隔：`frame:N[,every=M]` 丢掉第 N 帧及之后每第 M 帧的全部包；`burst:起点毫秒+时长毫秒` 丢掉这段时间内的全部视频包；`ge:P,R[,seed=S]` 为 Gilbert–Elliott 随机丢包（P 好→坏，R 坏→好）；`delay:毫秒` 让所有视频包晚到这么久（主控的 RTT 估计同样加上）。`frame`、`burst`、`ge` 的丢包发生在 RTX 与 FEC 恢复之后、按原始序号过滤，所以修不回来，用来量恢复路径。另有两条作用在收包入口、重传与 FEC 可以修复的规则，用来模拟真实网络：`net:P,R[,seed=S]` 为同样参数的随机丢包（媒体、RTX、FEC 包都会丢）；`rate:Mbps[,queue=毫秒]` 为瓶颈带宽，队列最多积压这么久的数据（默认 200 ms），超出的包丢弃，大帧因此要花真实的传输时间。注意被控的拥塞控制看不到这两条规则造成的延迟与丢包（反馈在注入之前生成），所以它们相当于“发送端没有察觉的链路变化”。报告中的 `smoothness` 给出解码帧间隔分位数、所有超过 100 / 250 / 500 ms 的间隔（`gaps_over_*`）与冻结总时长（`frozen_ms`）、丢包以外的停顿次数（`stalls_over_*`：间隔超出采集间隔）和解码时间相对采集时间的抖动，`network_drops`、`queue_drops`、`max_queue_ms` 记录 `net:` 与 `rate:` 规则的效果，`frame_bytes` 分别给出普通帧、长期参考标记帧与关键帧的大小；量流畅性时让被控画面持续变化。`--no-recovery` 让主控不声明 `video.recovery`，只用关键帧恢复；`--recovery-late` 让恢复帧也等到“修不好”才请求（不提前判定）；两者都用于 A/B 对照。被控的编码方式可以用 `Farwing.exe host --allow --encoder software`（或 `hardware`、`auto`）设置并保存，例如对比软件编码。调试构建也可以用环境变量 `FARWING_DEV_VIDEO_LOSS` 对普通观看窗口注入。

要让丢包、排队和延迟像真实网络一样作用在双方（被控的拥塞控制能看到，重传可以修复，浏览器观看者也受影响），在被控端设 `FARWING_HOST_LINK`，规则同 `--loss` 的 `net:`、`rate:`、`delay:`，例如 `FARWING_HOST_LINK="net:0.02,0.3;rate:12;delay:30"`。另有 `mtu:N`：在线路上（含 IP、UDP 与 SRTP）超过 N 字节的包全部丢失，模拟 MTU 比 1500 小的路径。被控端设 `FARWING_HOST_ENCODER=nvidia|amd|intel|software` 时只用这一类编码器，用于对比。每次连接结束时两端日志各有一行 `connection path summary`：最终路径（`route` 为 LAN / P2P / relay 等，`pair` 为候选对类型与协议）、两端的 NAT 行为（`local_nat` / `remote_nat`）、是否开启激进打洞与是否预测端口、网关端口映射的结果（`gateway_mapping`）；打洞过程（`NAT groups`、`punch round`）也记入日志。诊断包带有这些日志。`FARWING_DEV_HOST_PREPARE_MS=<毫秒>` 让被控在准备画面前多等这么久，用来模拟显示器变化后重新检查编码器（约 10–15 秒）时的首次连接。`FARWING_RECEIVE_MTU=<字节>` 设定每个收到的 UDP 包的读缓冲区（默认 2048），更长的包会被丢弃，用于模拟接收端缓冲区过小。被控发出的包按所选线路限定大小：局域网内按网卡 MTU（最多 1500 字节），经过公网、打洞或中继时为 1280 字节；`FARWING_PATH_MTU=<字节>` 可在被控端改为固定值。它作用在被控对每个包记下发送时间之后（视频、RTX、FEC、声音都经过同一条模拟链路），被控照常保留这些包用于重传。

要用别的解码器核对一次观看，在主控端设 `FARWING_DECODER_DUMP=<目录>`：Windows 硬件解码器收到的每个访问单元会按会话写成一个文件（`<进程号>-<序号>.h264` / `.h265` / `.obu`）。H.265 文件可以用 `ffmpeg -flags2 +showall -i <文件> -vf extractplanes=y -f framehash -hash sha256 -` 得到每帧亮度的哈希，与 `FARWING_REPLAY=<文件> cargo test --release --lib hevc::replay -- --ignored --nocapture` 的输出逐帧对照（要有 NVIDIA 显卡）。

弱网下被控在测得丢包后，用画面没用到的带宽发送 RS-FEC 修复包，让主控不等重传就补回丢失的包（[farwing-protocol.md](protocol/farwing-protocol.md) §6.4）；网络正常或带宽被画面用满时不发。对比时可在被控端设 `FARWING_FEC=0` 关闭（只在被控端有效，主控端没有这个开关）。播放窗口关闭时的日志中 `fec_packets_received` / `fec_packets_recovered` 是收到的修复包与用它们补回的包数。

要在本机看直连与中转的自动切换，在被控端设 `FARWING_DEV_DIRECT_LOSS=<百分比>[,<Unix 时间（秒）>]`：会话在直连上时丢掉这么多媒体包和切回前的压测包（连通检查不丢，像运营商对 P2P 流量做 QoS），切到中继后不再丢；给出时间时只丢到那一刻，用来看网络恢复后切回直连。主控日志的 `path switch` 行记录每次切换；主控加 `--log-level "info,webrtc_ice::agent::path=debug"` 可看到每秒的测量值。需要服务器提供 TURN。也可以在主控端设 `FARWING_DEV_PATH_LOSS=<类别>:<百分比>[,…][,until:<Unix 时间（秒）>]`（类别 `direct`、`udp-relay`、`stream-relay`），按主控判断的路径类别丢掉收到的媒体与压测包，用来看会话在直连、UDP 中转与 TCP / TLS 中转之间的选择（中转服务器在局域网内时被控会把经中转的路径当作局域网，被控端的开关这时不准）；`path switch` 行注明两条路径的类别（`direct`、`UDP relay`、`TCP/TLS relay`）。

被控探测可用带宽时用高精度定时器按 2 ms 节拍发送探测包。`connect` 另有测量用的隐藏参数 `--dev-auto-quality <2–4>`：自动画质从指定档位开始，不使用也不保存观看端记住的档位，让每次测量从同一档位开始。

量浏览器观看者的丢包恢复时，可以在被控端设环境变量 `FARWING_HOST_VIDEO_LOSS=N,M`：每个视频轨跳过发送的第 N 帧及之后每第 M 帧（关键帧除外），这些包占用序号但不发送、也不留作重传，接收端修不回来。

量播放窗口本身（画面上屏节奏）时，`connect` 有几个不在帮助中显示的测量参数：`--dev-loss "<规则>"`（同 `--loss`）、`--dev-no-recovery`、`--dev-cinema true|false`（以观影模式或非观影模式开始，不保存）。关闭窗口时日志写出 `native viewer session performance summary`（渲染帧率、渲染间隔、≥100 / 180 / 500 ms 的停顿次数、因新帧到达而未显示的帧数、相邻两张上屏画面的内容间隔 `content_steps_over_50ms` / `content_step_max_ms` 等）。播放窗口在低延迟播放时默认“追帧”：解码器停顿后成批解出的画面最多两张排队，按屏幕刷新依次显示，而不是直接跳到最新一张；只在屏幕刷新率不低于码流帧率 1.5 倍、且画面是被压住（不是丢掉）时生效。观影模式下自动关闭（播放缓冲已让画面均匀输出）。设 `FARWING_VIEWER_CATCHUP=0` / `=1` 强制关闭 / 开启（见 [selftest-results.md](selftest-results.md) §19）。

`dev plugins` 检查已安装的插件：按观看窗口相同的方式（独立宿主进程、ABI 校验、节点程序描述）加载每个视频节点，确认超出范围的参数被拒绝；装有画面滤镜示例时，再在显卡上用已知画面运行色彩调整、像素化与锐化并检查结果。插件目录与运行时相同（程序旁的 `plugins/`，没有时用 `%LOCALAPPDATA%/Farwing/plugins/`）。

```powershell
Farwing.exe dev plugins
```

`dev input` 按脚本向被控端发送键鼠（与观看窗口相同的输入通道，但没有窗口），用于验证被控端注入：

```powershell
Farwing.exe dev input --device-id <ID> --script keys.txt [--screen <屏幕编号>] [--hold-ms 40]
Farwing.exe dev input --direct 192.168.1.20 --script keys.txt
```

脚本每行一步，`#` 开头为注释。按键按美式键盘的物理位置发送，被控端的布局与输入法决定最终字符。

| 步骤 | 说明 |
| --- | --- |
| `text <文本>` | 逐字符按键，需要时自动按 Shift；`\n` 回车，`\t` Tab，`\\` 反斜杠；只支持可打印 ASCII |
| `key <组合>` | 依次按下、反序抬起，如 `ctrl+a`、`ctrl+shift+esc`、`win+d`、`f5`、`volumeup`、`mediaplaypause` |
| `down <键>` / `up <键>` | 单独按下或抬起，用于长按 |
| `repeat <键> <次数> <间隔毫秒>` | 按住并发送自动重复 |
| `lock caps=on num=off scroll=off` | 发送锁定键状态（未写的项为 off） |
| `move <x> <y>` | 鼠标移到屏幕上的相对位置（0..1） |
| `rel <dx> <dy>` | 相对移动（被控端的相对鼠标输入，光标位移受系统指针加速影响） |
| `click <left\|right\|middle\|x1\|x2> [次数]`、`press <键>`、`release <键>` | 鼠标按钮 |
| `wheel <dy> [dx]` | 滚轮，单位 1/120 格 |
| `system <taskmgr\|desktop\|taskview>` | 系统命令；`sas`、`lock` 会锁定桌面，需要 `--allow-disruptive` |
| `sleep <毫秒>` | 等待 |
| `pull` | 获取被控剪贴板文本并打印（需要“剪贴板”权限） |

按键名还包括 `enter`、`esc`、`tab`、`backspace`、`space`、`equal`、方向键、`home`、`end`、`pageup`、`pagedown`、`insert`、`delete`、`capslock`、`numlock`、`scrolllock`、`pause`、`printscreen`、`apps`、左右 `ctrl` / `shift` / `alt` / `win`（`rctrl`、`ralt` 等）、`f1`–`f12`、小键盘 `kp0`–`kp9`、`kpenter` 等，以及单个字符（`key a`、`key 1`、`key ;`）。退出时（包括出错与 Ctrl+C）会抬起所有仍按住的键和按钮。主控端使用内存剪贴板，不读写本机 Windows 剪贴板。
