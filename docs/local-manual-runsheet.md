清单中能在一台电脑上完成、但需要人操作界面（G）或会打断当前使用（D：锁屏、睡眠、注销、重启、拔显示器等）的项目。命令行、网页端与模拟链路能测的已在 [selftest-results.md](selftest-results.md) §75 全部通过；需要两台机器的见 [dual-machine-runsheet.md](dual-machine-runsheet.md)。编号与预期取自 [manual-test-checklist.md](manual-test-checklist.md)。

- “结果”列填 ✅ / ❌ / 备注；不对时写上大致时间，日志在 `%LOCALAPPDATA%\Farwing\logs` 与 `C:\ProgramData\Farwing\host\logs`。
