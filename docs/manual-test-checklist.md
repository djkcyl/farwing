# Farwing 0.1.0 测试清单

全部测试项目都在这一份清单里。“环境”说明在哪里测：

- **本机**：一台电脑上用命令行、浏览器或模拟链路即可完成。
- **本机·界面**：一台电脑，但需要人操作设备中心或观看窗口。
- **本机·打断**：一台电脑，但会打断使用（锁屏、睡眠、注销、重启、拔显示器、开测试签名等）。
- **双机**：需要两台电脑、真实局域网或公网；标“可选”的缺少条件时跳过。

“结果”填 ✅（通过）、❌（不通过）或“部分”；“备注”写测到的数值、与预期的差别或没测到的部分。已填的本机结果是在 2026-10-30—31 重建的部署上测的，发现的问题与修复见 [selftest-results.md](selftest-results.md) §78。

双机项目建议的顺序：第 0 节准备 → 同一局域网 → 弱网（第 5、29、30 节等）→ 不同网络与公网（第 15 节）→ 多人转发（第 35 节）→ 卸载（18.4、21.6 最后做）。出现 ❌ 或觉得不对时，两台都运行测试包里的 `收集日志.ps1`（右键 → 使用 PowerShell 运行），把桌面上生成的 zip 发回来，并写上大致时间。

日志在 `%LOCALAPPDATA%\Farwing\logs`（多 profile 时在 `profiles\<名称>\logs`）；安装后台服务后，服务与后台主机的日志在 `C:\ProgramData\Farwing\host\logs`。需要更详细的日志时，可在任意命令前加 `--log-level "info,farwing::transport=debug"` 之类的过滤串（语法同 `RUST_LOG`）。

“访客”用访问码或本机确认连接一次；“受信任设备”由被控记住，以后无需访问码（`access-model.md` §2.2–2.4）。

## 37. 端到端加密设置

设计见 [camera-design.md](protocol/camera-design.md) §8。服务器设置“多人转发”页下方的“端到端加密”三档：强制、允许兼容（默认）、关闭；客户端“设置 → 网络 → 加密”有“只接受端到端加密”（默认关）。本机项目用三个观看者（阈值 3）。
