# Farwing 0.1.0 待测清单（双机 / 局域网 / 公网）

这是需要你在两台机器上执行的全部项目，每项写明了步骤和预期，不用再对照其他文档。单机已经验证通过的项目不在这里（结果见 [selftest-results.md](selftest-results.md)）；编号与 [manual-test-checklist.md](manual-test-checklist.md) 一致，方便对照。

- **H** = 被控机，**C** = 主控机；alice 在 H、C 都登录，bob 是 alice 的好友。
- 按批次顺序做，可以最少地改动网络和安装状态。
- 在“结果”列填 ✅ / ❌ / 备注。失败时请保留两端日志与一个诊断包：
  - 便携运行：`%LOCALAPPDATA%\Farwing\logs`；多 profile 时在 `%LOCALAPPDATA%\Farwing\profiles\<名称>\logs`
  - 安装后台服务后，服务的日志：`C:\ProgramData\Farwing\host\logs`
- 需要更详细的日志时，在命令前加 `--log-level "info,farwing::transport=debug"`。

### 多人：控制权与多人观看流（alice@C + bob，有第三台机器更好）

规则：
- **控制权先到先得：** 同一时刻只有一人能开启键鼠控制，开启即获得控制权。
- **只由持有者释放：** 持有者关闭键鼠控制、断开，或被收回控制权限时才释放；长时间不操作不会释放，别人也不能抢。
- **多人观看流：** 没有控制权的人统一看同一路 1080p 档 · 60 FPS · 观影模式的画面（同一屏幕只编码一次），画质菜单锁定。
- **持有者：** 用自己的画质设置，可以关闭观影模式、使用低延迟。
- **一人连接时：** 没有任何限制。

准备：
- 在 alice 的“好友”页给 bob 授予 H 的“键鼠控制”，测 8.8 时再加“麦克风”。
- 上次开着键鼠控制的人，独自连接 H 时会自动恢复控制。开始前，alice 先单独连接 H，在工具栏关闭键鼠控制再断开（bob 如果之前开过，也这样做一次），否则 16.1 中先连上的人会直接拿到控制权。
- H 的日志里可以看这些关键词：
  - `host control token changed`：控制权变化，`holder=None` 表示无人持有；
  - `participant stream policy shared=true / false`：某人是否进入多人观看流；
  - `participant leads a new shared encoder group`：新开一路编码；
  - `joined a shared encoder as a follower`：加入已有的一路编码。
