# Farwing 双机测试清单（第十五版）

只列必须在两台真实机器、真实网络上才能知道是否可用的项目。单机已经验证过的功能（画质档位、帧率、首帧时间、音质、FEC、多人控制权流程等）和从代码就能确定的逻辑（权限开关、提示文字等）不在这里。编号沿用完整清单（manual-test-checklist）的编号，合并的项目写成范围。

- **H** = 被控机，**C** = 主控机；alice 在 H、C 都登录。bob 只在“多人”“多人转发”和标明的可选项目中用到；多人转发最好有第三台电脑（或手机热点下的另一台）。
- 按顺序做：先在同一局域网完成第 1 批，再做弱网、跨网络，最后卸载。
- “结果”列填 ✅ / ❌ / 备注。出现 ❌ 或觉得不对时，两台都运行测试包里的 `收集日志.ps1`（右键 → 使用 PowerShell 运行），把桌面上生成的 zip 发回来，并写上大致时间。
- 标“可选”的项目缺少条件时跳过。

需要路由器的限速 / QoS，或在 H 上用 clumsy（clumsy.github.io）按 C 的地址过滤。

| 编号 | 步骤 | 预期 | 结果 |
| --- | --- | --- | --- |
| 5.1、5.5、30.2 | 把 H→C 限速到 3 Mbps 后第一次连接并观看动态画面；再改为约 2% 丢包 | 限速时码率不超过限速、画面流畅；丢包时画面不长时间卡住，很快恢复。记录 HUD 的码率、帧率与丢包 | |
| 15.8 | 直连建立后，只对直连路径制造约 50% 丢包（clumsy 按 C 的直连地址过滤，不影响到服务器的流量），持续 5 分钟后去掉 | 约 10 s 内切到中继（C 日志 `path switch: cost …`），画面恢复流畅；丢包期间每隔 60 s、120 s… 压测一次直连（`path load test of …`），不切回；去掉丢包后下一次压测通过即切回直连（`(retry)`） | |
