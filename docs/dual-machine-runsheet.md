# Farwing 双机测试清单（第二十二版）

只列必须在两台真实机器、真实网络上才能知道是否可用的项目。单机已经验证过的功能（画质档位、帧率、首帧时间、音质、FEC、多人控制权流程等）和从代码就能确定的逻辑（权限开关、提示文字等）不在这里。编号沿用完整清单（manual-test-checklist）的编号，合并的项目写成范围。

- **H** = 被控机，**C** = 主控机；alice 在 H、C 都登录。bob 只在“多人”“多人转发”和标明的可选项目中用到；多人转发最好有第三台电脑（或手机热点下的另一台）。
- 按顺序做：先在同一局域网完成第 1 批，再做弱网、跨网络，最后卸载。
- “结果”列填 ✅ / ❌ / 备注。出现 ❌ 或觉得不对时，两台都运行包里的 `收集日志.ps1`（右键 → 使用 PowerShell 运行），把桌面上生成的 zip 发回来，并写上大致时间。
- 标“可选”的项目缺少条件时跳过。
- 编号以 R 开头的是近两版新增：访问码定期更换、邀请链接、记录与通知、网页端性能监控、仅音频切回后的码率、网页登录期限；上一版新增 R11、R12（请求本次控制、指针共享）与 R13（显示器断开时的虚拟显示器兜底）；本版新增 R14（断网的主控立即离开）与 R15（网页观看者在有人加入时不停顿）。
