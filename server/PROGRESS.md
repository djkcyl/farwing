# Farwing 自建分支进度

更新于 2026 年 11 月 21 日。分支基于上游 `v1.0.2-beta.8`。Windows 主控和被控、iOS 主控、网页主控可使用同一个自建服务地址。

| 模块 | 当前实现 | 验证情况 |
| --- | --- | --- |
| 服务端 | HTTPS/WSS、设备自动注册、设备目录、访问控制、会话接管和 WebRTC 信令 | 6 项集成测试通过，覆盖地址登记、旧版配对、重连、会话接管及访问范围 |
| Windows | 原生连接设置和设备列表。修复切换自建服务器后，界面丢弃已返回的设备列表而持续转圈的问题 | 实机日志已确认注册、设备目录请求和 WSS 信令握手成功。修复版通过回归检查和 Windows x64 构建，仍待在 Windows 实机验证登录页进入「我的设备」 |
| 网页主控 | 同源页面、设备列表及 WebRTC 远程会话 | 有一场与 Windows 实机建立 WebRTC 直连并发送视频首帧的记录 |
| iOS 主控 | SwiftUI 界面、按地址保存凭据、启动加载主机列表、WebRTC 视频和远程输入 | Xcode 26.3 `iphoneos` 构建通过，编译器报告两处 Swift 并发警告。iPad 真机的视频首帧及输入待验证 |

## 复测

1. 在 Windows 保存自建服务地址，确认「连接自建服务器」页进入「我的设备」。重新启动应用，确认能加载设备列表。
2. 在 Windows 被控端开启「允许被控」，从网页或 iPad 连接同一台主机，检查首帧能否显示，以及鼠标、触摸和键盘输入能否到达被控端。
3. 若 Windows 被控端需要无屏运行，另外验证虚拟显示器能被系统识别和采集。

地址模式的准入范围和跨 NAT 配置见[服务端部署说明](README.md)。设备协助码、远程唤醒、电源操作、上游会员和升级服务尚未接入。
