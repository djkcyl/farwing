# Farwing 0.1.0 部署与使用教程

Farwing 是自己部署服务器的远程桌面，由两部分组成：

- **服务端** `farwing-server`：账号、设备与连接协调，网页端（管理与浏览器观看），内置中转（TURN），多人转发。一个程序，一个数据目录，所有设置在网页端完成。
- **客户端** `Farwing-v0.1.0-windows-x86_64.exe`：Windows 10/11 x64，主控（连别人）与被控（被别人连）是同一个程序，免安装。

客户端与服务端必须来自同一个包，不与旧测试版互通。

## 一、准备

- 一台客户端都能访问到的服务器：
  - 推荐 Linux 云服务器（x86_64 或 aarch64，带 systemd，1 核 1 GB 足够；常见发行版都可以，程序是静态链接的）。
  - 也可以是家里或公司的 Windows / Linux 电脑，此时需要公网 IPv4，并在路由器上转发端口（见“三、放行端口”）。
- 一个域名（推荐）：A 记录指向服务器的公网 IPv4。有域名时证书自动申请、浏览器与客户端都直接信任；没有域名也能用，见“五、没有域名”。
- 服务器的 TCP 443 没有被其他程序（例如 Nginx）占用；被占用时见“六、用其他端口”。

## 二、安装服务端（Linux）

把 `server/farwing-server-0.1.0-linux.tar.gz` 上传到服务器，登录服务器后：

```sh
tar xzf farwing-server-0.1.0-linux.tar.gz
cd farwing-server-0.1.0-linux
sudo sh install.sh
```

脚本完成这些事：

- 按 CPU 架构安装 `/usr/local/bin/farwing-server`，创建系统用户 `farwing`；
- 安装并启动 systemd 服务 `farwing-server`（开机自启，异常退出自动重启），网页与接口直接监听 TCP 443，不需要 Nginx 等反向代理；
- 本机运行着 ufw 或 firewalld 时放行所需端口；
- 打印**初始化码**（24 小时有效）。

数据目录是 `/var/lib/farwing-server`（数据库、证书、壁纸）。

选项：`--port 端口` 改用其他端口；`--no-firewall` 不修改本机防火墙。

## 三、放行端口

云服务器还要在云厂商控制台的**安全组 / 防火墙**中放行（入方向）；服务器在路由器后面时，在路由器上把同样的端口转发到服务器：

| 端口 | 用途 | |
| --- | --- | --- |
| TCP 443 | 网页端、客户端接口、证书自动申请 | 必需 |
| UDP 3478 | 中转 | 必需 |
| UDP 49160–49200 | 中转数据 | 必需 |
| UDP 3481 | 多人转发（同一台电脑 3 人起同时观看） | 推荐 |
| TCP 3478 | TCP 中转（UDP 被封的网络） | 推荐 |
| TCP 5349 | TLS 中转（只放行 HTTPS 类端口的网络，例如部分公司网络） | 推荐 |
| UDP 3479–3480 | NAT 类型探测（帮助判断能否直连） | 推荐 |

一般情况把表中全部端口放行即可。确实只想开必需端口时，见“七、精简端口”。

## 四、网页初始化（有域名）

1. 浏览器打开 `https://你的域名/setup`。此时证书还是临时自签的，浏览器提示不安全，选择“高级 → 继续访问”。
2. 填写：
   - **初始化码**：安装脚本打印的那个。
   - **管理员**：用户名（默认 admin）与密码。
   - **公开地址**：`https://你的域名`（不带端口）。
   - **证书**：选“自动申请”。域名填你的域名，填联系邮箱，勾选“同意证书颁发机构的服务条款”（默认 Let's Encrypt）。
   - **中转**：选“内置中转”，**公网 IP** 填服务器的公网 IPv4。云服务器上预填的往往是内网 IP，一定要改。
   - **账号**：“邀请码注册”（允许别人用邀请码自己注册）、“游客功能”（允许不登录的客户端与浏览器用设备 ID / 短号加访问码连接）按需要打开。
3. 点“完成”。证书一般在一分钟内签发好，之后打开 `https://你的域名` 不再有警告；进度在网页端“服务器设置 → 证书 → 签发状态”中查看。证书到期前自动续期，不需要重启。

证书自动申请要求：域名已解析到这台服务器，TCP 443 能从外网访问，服务器有系统 CA 证书（`ca-certificates` 包，常见发行版默认已装）。

## 五、没有域名

“证书”选“自签名”，在“证书名称”中加上服务器的公网 IP；公开地址填 `https://公网IP`。其余同上。

- 证书指纹在网页端“服务器设置 → 证书 → 证书指纹”。客户端第一次连接时会显示指纹，核对一致后再信任。
- 浏览器每次打开网页端都会提示证书不安全，选择继续访问即可。
- 已有证书时可以选“上传证书”，上传证书链与私钥（PEM）。

## 六、用其他端口

TCP 443 已被占用（例如服务器上已有网站）时，换一个端口安装：

```sh
sudo sh install.sh --port 8443
```

公开地址填 `https://你的域名:8443`，安全组放行 TCP 8443 代替 443，客户端的服务器地址填 `你的域名:8443`。

证书自动申请时，证书颁发机构只会访问域名的 443 或 80 端口来验证，按外网能到达 Farwing 的端口选择：

| 外网能到达 | 验证方式 | 设置 |
| --- | --- | --- |
| 443（直接监听，或路由器把外网 443 转发到 Farwing 的端口） | TLS-ALPN-01 | 公开地址用 `https://你的域名`（不带端口），不需要其他设置 |
| 80 | HTTP-01 | 初始化时证书先选“自签名”；完成后在“服务器设置 → 证书”改为“自动申请”，“HTTP 监听地址”填 `0.0.0.0:80`，并放行 TCP 80（续期也要用，保持开放） |
| 都不能（80、443 都被其他程序占用，或宽带封了这两个端口） | — | 用“上传证书”：在别处申请（例如 acme.sh 的 DNS 验证）后上传，到期前重新上传；或者用自签名 |

已安装后改端口：重新运行 `sudo sh install.sh --port 新端口`，再到网页端把公开地址改成新端口。

## 七、精简端口（可选）

只开“必需”的端口时，在网页端把没开的功能关掉，客户端就不会去尝试：

- 没开 TCP 3478 / 5349：“服务器设置 → 中转与探测”中清空“TCP 监听地址”/“TLS 监听地址”。
- 没开 UDP 3479–3480：“中转与探测 → NAT 探测端点”中移除端点。
- 没开 UDP 3481：“多人转发”中关闭“启用多人转发”（多人观看时由被控直接给每人发一份，更费被控的上行带宽）。

## 八、服务端用 Windows

`server/windows/farwing-server.exe` 是同一个服务端的 Windows 版，适合测试或家里的小规模使用。

1. 把它放进一个空目录（例如 `C:\Farwing`），在该目录打开 PowerShell 运行：

   ```powershell
   .\farwing-server.exe --listen 0.0.0.0:443
   ```

   不加 `--listen` 时监听 TCP 8443。窗口中打印初始化码；数据保存在程序旁边的 `data` 目录。窗口要一直开着。
2. Windows 防火墙：首次运行时弹窗选“允许访问”；或在管理员 PowerShell 中运行

   ```powershell
   New-NetFirewallRule -DisplayName "Farwing Server" -Direction Inbound -Program "C:\Farwing\farwing-server.exe" -Action Allow
   ```

3. 路由器上转发“三、放行端口”中的端口，然后按“四”或“五”初始化。

需要新的初始化码时：`.\farwing-server.exe setup-code`。

## 九、网页端管理

用管理员登录 `https://你的域名`，侧栏“管理”中：

| 页面 | 用途 |
| --- | --- |
| 服务器概览 | 在线设备、会话、证书指纹、中转状态 |
| 账号 | 创建账号、重置密码、停用 |
| 邀请码 | 生成邀请码；对方在登录页点“使用邀请码注册”（需要打开“邀请码注册”） |
| 全部设备、会话 | 所有设备与正在进行的连接 |
| 连接记录 | 所有账号的连接记录（谁、何时、怎么连、画面概况、文件传输） |
| 客户端更新 | 发布更新公告，客户端检查更新时看到 |
| 中转节点 | 在其他服务器上加中转节点（添加后在节点上运行页面给出的加入命令） |
| 服务器设置 | 基本、证书、中转与探测、多人转发、账号与网页端、限额与超时、备份 |
| API 令牌 | 用脚本调用管理接口 |
| 审计日志 | 登录与管理操作记录 |

设置保存后立即生效，不需要重启服务。

普通用户登录网页端后可以管理自己的设备、好友、收藏与账号安全，查看“记录”（本账号设备的每次连接与账号变动）和“通知”（新设备登录、有人连接、设备离线、好友申请等，接收哪些在“账号与安全”中设置），也可以直接在浏览器中观看和控制自己的电脑（推荐 Chrome 或 Edge）。客户端侧栏也有“记录”与“通知”，内容相同。

## 十、客户端

### 1. 登录

1. 运行 `Farwing-v0.1.0-windows-x86_64.exe`。Windows 防火墙询问网络访问时选“允许”。
2. “连接服务器”：服务器地址填 `你的域名`（用其他端口时 `你的域名:端口`），点“检查证书”。
   - 证书受系统信任（自动申请的证书）时直接进入下一步。
   - 自签名证书会显示指纹，与网页端的证书指纹核对一致后点“信任此证书并继续”。
3. “登录账号”：填用户名与密码。同一账号下的电脑会出现在“设备 → 我的设备”中。

### 2. 被控电脑（被别人连接）

- “本机”页打开“允许连接本机”。设备 ID 与短号也在这里，告诉别人用于连接。
- **安装后台服务**（推荐）：“设置 → 后台服务与驱动 → 安装服务”（需要管理员授权）。装好后锁屏、未登录 Windows 时也能连接和操作，开机自动在线。
- 自己账号的其他电脑可以直接连接；好友按你在“好友”页给的权限；其他人需要访问码或由你在本机确认（“本机 → 访问码”）。
- 临时访问码默认每天自动更换一次，可在访问码设置（齿轮）中改为每次连接后、每小时到每周，或从不。
- “复制邀请”复制设备 ID、短号和访问码；填了服务器时还带一个网页链接，对方用浏览器打开即自动填好，直接观看。

### 3. 主控电脑（连接别人）

- “设备”页上方输入设备 ID、短号或地址后点“连接”，或在下面的列表中选择。
- 观看窗口顶部的标题栏有画质、显示器、键鼠控制、文件、参与者等菜单。
- **画质**：自动、原画、超清、高清、流畅（720p · 60 FPS，约 1.5 Mbps）、自定义。“自动”按网络调整；手动选的档位频繁卡顿时，画面上方提示可以改为低一档。
- 怎么连自动选择，性能监控中显示为 `LAN`（局域网直连）、`P2P`（经服务器打洞直连）、`TURN`（中转，含 UDP / TCP / TLS）或 `SFU`（多人转发）；标题栏菜单中“使用中转”可以强制走中转。
- **性能监控**：画面右下角，默认精简（时长、连接方式、帧率、码率、往返、丢包、画质与声音电平），菜单中可改为详细或关闭。网页端观看相同。

### 4. 多人同时观看

- 默认最多 8 人同时连接一台电脑。键鼠控制权同一时刻只有一人，先到先得。
- 没有控制权的观看者看同一路 60 FPS 画面，画质可选自动、高清（1080p）、流畅（720p）。选“自动”时网速不够会自动换到流畅，网速恢复后换回。
- 同时观看达到 3 人时，被控只给服务器发一份画面，由服务器的多人转发分给每个人（默认端到端加密，服务器看不到画面；参与者面板显示 `SFU · E2EE`）。

### 5. 不使用服务器

同一局域网内可以不要服务器：在“连接服务器”中点“不使用服务器 · 局域网直连”，被控与主控在“设备 → 附近”中互相看到，用访问码或配对后连接。

客户端功能的完整说明见 `docs/client-usage.md`。

## 十一、排错

| 现象 | 处理 |
| --- | --- |
| 网页打不开 | `systemctl status farwing-server` 看服务是否运行；检查安全组与本机防火墙是否放行 TCP 443；`journalctl -u farwing-server -n 50 --no-pager` 看日志 |
| 证书一直没签发 | “服务器设置 → 证书 → 签发状态”看原因：域名没解析到本机、443 从外网不通、公开地址不是 443 端口又没有设置 HTTP 监听地址（见“六”） |
| 客户端提示证书不受信任 | 自签名证书时正常，核对指纹后信任；用了自动申请却仍不受信任，说明证书还没签发好 |
| 能登录但连不上、或画面一直黑 | 检查中转的公网 IP 是否填的是公网 IPv4、UDP 3478 与 49160–49200 是否放行；网页端“服务器设置 → 中转与探测 → 运行状态”应显示监听地址 |
| 连接只能走中转、画面慢 | 公司或校园网常见；放行 TCP 3478、5349 能让更多网络连上 |
| 忘了管理员密码 | `sudo runuser -u farwing -- farwing-server --data-dir /var/lib/farwing-server setup-code` 生成新的码，打开 `https://你的域名/setup` 恢复管理员 |
| 需要反馈问题 | 两台电脑都运行 `client/收集日志.ps1`（右键 → 使用 PowerShell 运行；装了后台服务的电脑以管理员身份运行），把桌面上生成的 zip 发回，写上出问题的大致时间；服务端日志用 `journalctl -u farwing-server --since "1 hour ago" > server.log` 导出 |

## 十二、升级、备份与卸载

**升级服务端**：上传新版的 tar.gz，解压后再运行一次 `sudo sh install.sh`。脚本沿用原来的端口，数据与设置保留。客户端直接用新版的 exe 替换（装了后台服务的电脑，在“设置 → 后台服务与驱动”中点“更新服务”）。

**备份**：

```sh
sudo systemctl stop farwing-server
sudo tar czf farwing-backup-$(date +%F).tar.gz -C /var/lib farwing-server
sudo systemctl start farwing-server
```

恢复时停止服务、把目录解压回 `/var/lib`（属主 `farwing`）后启动。网页端“服务器设置 → 备份”可以单独导出 / 导入设置。

**卸载服务端**：

```sh
sudo systemctl disable --now farwing-server
sudo rm -rf /etc/systemd/system/farwing-server.service /etc/systemd/system/farwing-server.service.d /usr/local/bin/farwing-server
sudo systemctl daemon-reload
sudo userdel farwing
sudo rm -rf /var/lib/farwing-server    # 数据，确认不再需要后再删
```

**卸载客户端**：先在“设置 → 后台服务与驱动”中卸载服务与驱动，再删除 exe；数据在 `%LOCALAPPDATA%\Farwing`。

## 十三、已知情况

- 驱动用项目自签名证书签名：安装虚拟显示或输入驱动时，程序请求管理员授权并把证书 `CN=Farwing Drivers` 加入本机信任。虚拟声卡还需要 Windows 测试签名模式。
- 新装或换了显卡、驱动的电脑第一次被连接前，被控会花约 10 秒检查编码能力（只做一次）。
- 客户端日志：便携运行在 `%LOCALAPPDATA%\Farwing\logs`；后台服务在 `%ProgramData%\Farwing\host\logs`。
- 这一版尚未在真实环境验证：Linux 服务端的实际运行（只验证了交叉编译与安装脚本的流程）、Let's Encrypt 正式签发（只用测试 CA 验证过）、systemd 加固选项在各发行版上的兼容性。遇到问题请附上 `journalctl -u farwing-server` 的输出。
